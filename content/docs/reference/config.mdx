---
title: YAML 配置参考
description: ByteHop v0.1 支持的顶层结构、字段、默认值和静态配置边界。
---

顶层只接受 `server`、`auth`、`resources` 与 `access`。未知字段会导致校验失败。

## `server`

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `listen` | `:8443` | 监听地址；明文模式必须是 loopback |
| `public_url` | 无，必填 | 绝对 HTTP(S) URL，不允许 path / query / credential |
| `instance_name` | `ByteHop` | UI 显示名称，1–64 bytes |
| `environment` | `default` | 环境标记，例如 `production` |
| `data_dir` | `./data` | SQLite 状态目录 |
| `web_dir` | 内嵌 Web | 可选的外部静态 UI 目录 |
| `session_ttl` | `12h` | 控制面 Session TTL |
| `default_lease_ttl` | `30m` | 未显式请求时的 Lease TTL，仍受 policy 上限限制 |
| `max_json_result_bytes` | `16777216` | CLI JSON envelope 最大响应体 |
| `tls_cert_file` | 无 | 内建 TLS 证书，与 key 成对配置 |
| `tls_key_file` | 无 | 内建 TLS 私钥 |
| `allow_insecure_http` | `false` | 只允许 loopback 开发 HTTP |

## `auth.local.users`

```yaml
auth:
  provider: local
  local:
    users:
      "alice@example.com":
        password: "${ALICE_PASSWORD}"
        groups: [data, operations]
        admin: true
```

v0.1 只支持 `provider: local`，且至少需要一个用户。`admin` 默认 `false`。

## `resources.<name>`

Resource 名必须匹配 `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`。

| 字段 | 是否必需 | 说明 |
| --- | --- | --- |
| `description` | 否 | 面向用户和 Agent 的简短说明 |
| `kind` | 是 | `http`、`clickhouse`、`elasticsearch` |
| `upstream` | 是 | HTTP(S) URL；可含 base path，不可含 credential / query / fragment |
| `openapi` | 否 | 本地 OpenAPI 文件，用于操作发现 |
| `health_path` | 否 | 健康探测路径；各 kind 有默认值 |
| `credential` | 是 | 恰好一个主认证机制，可附加 `headers` |
| `tls` | 否 | 上游 CA、server name 和验证开关 |

### Credential

```yaml
credential:
  basic:
    username: service_ro
    password: "${SERVICE_PASSWORD}"
  headers:
    Cookie: "session=${SERVICE_SESSION}"
```

主机制从 `basic`、`bearer`、`api_key`、`header` 或仅 `headers` 中选择一个。`api_key` / `header` 结构均为 `{name, value}`。附加 headers 不能覆盖已有 Basic / Bearer 的 `Authorization`。

### 上游 TLS

```yaml
tls:
  ca_file: "./certs/internal-ca.pem"
  server_name: "service.internal"
  insecure_skip_verify: false
```

相对 `ca_file`、`openapi`、证书与数据路径均基于 YAML 文件所在目录解析。

## `access`

```yaml
access:
  - subjects: ["group:data", "user:lead@example.com"]
    resources: [analytics]
    max_ttl: 30m
```

必须至少有一条显式策略。subject 需要 `user:` 或 `group:` 前缀；Resource 必须已定义。省略 `max_ttl` 时使用 `default_lease_ttl`。

## 静态字段

`listen`、`public_url`、`data_dir`、`web_dir`、内建 TLS cert/key 和 `allow_insecure_http` 变更需要重启。其余字段经过全量校验后可热重载。
